# 🚀 Full-Stack Developer Take-Home Assignment

## AI-Powered Code Review System

---

## 📋 Overview

Build a web application that allows developers to submit code snippets for AI-powered review and feedback. The system should handle multiple concurrent reviews, store review history, and provide insights on code quality trends.

**⏱️ Time Estimate:** 5 hours of focused development time

**⏰ Deadline:** Complete within 7 days of receiving this assignment

---

## 🛠️ Required Technology Stack

### Frontend

- **React.js** with **TypeScript**
- Functional components with hooks
- Responsive design (mobile-friendly)
- Code syntax highlighting library (e.g., react-syntax-highlighter)

### Backend

- **Python** with **FastAPI**
- Async request handling
- Pydantic models for validation
- Auto-generated API documentation

### Database

- **MongoDB**
- Efficient indexing for queries
- Connection pooling

### AI Integration

- **OpenAI API** (or similar LLM service)
- Custom prompt engineering for code review
- Error handling and retry logic

### Deployment

- Deploy both frontend and backend to cloud platforms
- Provide publicly accessible URLs

---

## ✅ Core Features Required

### 1. Code Submission Interface (Frontend)

- [ ]  Form to submit code snippets with programming language selection
- [ ]  Real-time syntax highlighting for submitted code
- [ ]  Display review status (pending, in-progress, completed, failed)
- [ ]  Loading states and error handling for all API calls

### 2. AI Code Review Service (Backend)

- [ ]  Integrate with OpenAI API to analyze code snippets
- [ ]  Generate structured feedback including:
    - Code quality score (1-10)
    - Identified issues and suggestions
    - Security concerns
    - Performance recommendations
- [ ]  Handle concurrent review processing

### 3. Review Management (Backend + Database)

- [ ]  Store code submissions and reviews in MongoDB
- [ ]  Track review status and timestamps
- [ ]  Implement basic rate limiting (max 10 reviews per IP per hour)
- [ ]  Background job processing for reviews

### 4. Analytics Dashboard (Frontend)

- [ ]  Display review history with filters (language, date range, score)
- [ ]  Show aggregate statistics (average quality score, common issues)
- [ ]  Export review data as CSV

---

## 🔗 API Endpoints (Minimum Required)

```
POST /api/reviews - Submit code for review
GET /api/reviews/{id} - Get specific review
GET /api/reviews - List reviews with pagination/filters
GET /api/stats - Get aggregate statistics
GET /api/health - Health check endpoint

```
